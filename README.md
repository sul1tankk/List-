# Лист — читать и понимать

Личная веб-читалка с переводом английских слов на русский.

## Возможности

- Загрузка PDF, EPUB, FB2 и TXT до 30 МБ.
- Перевод слова по нажатию через MyMemory.
- Светлая и тёмная темы, изменение размера текста.
- Сохранение книг и страницы в IndexedDB текущего браузера.
- Оглавление и личная библиотека.
- Адаптивный интерфейс для компьютера и телефона.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Откройте адрес, указанный в терминале.

```bash
npx tsc --noEmit
npm run build
npm start
```

## Размещение на Vercel

Импортируйте этот репозиторий, выберите ветку `main` и корневую папку проекта. Файл `vercel.json` задаёт сборку Next.js для Vercel, установку через `npm ci` и каталог `.next`. Переменные окружения для читалки не нужны.

Для проверки такой же сборки локально:

```bash
npx next build --webpack
npx next start
```

Обычный `npm run build` сохраняет исходную сборку Vinext для Cloudflare / ChatGPT Sites.

## Стек приложения

React 19, TypeScript, Vinext/Vite, Cloudflare Workers, IndexedDB.

## Основные файлы

- `app/page.tsx` — интерфейс и управление чтением.
- `app/book.ts` — импорт книг, разбиение на страницы, сохранение.
- `app/globals.css` — темы и адаптивные стили.
- `app/api/translate/route.ts` — резервный серверный перевод.

## Данные и ограничения

Книги остаются на устройстве. Прогресс не синхронизируется между браузерами; очистка данных сайта удаляет книги и сохранённые страницы. Для перевода нужен интернет: выбранное слово передаётся MyMemory. Возможны лимиты сервиса. PDF открываются как текст с исходными номерами страниц, переводом слов и сохранением страницы. Изображения и исходная вёрстка PDF не отображаются. Сканы без текста требуют предварительного OCR. PDF с паролем и EPUB с DRM не поддерживаются.
